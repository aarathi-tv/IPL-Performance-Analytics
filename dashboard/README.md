# 🏏 IPL Performance Analytics

An interactive Tableau dashboard analyzing IPL team, batting, and bowling performance from **2008–2023**.

The dashboard brings together team KPIs, player rankings, batting performance, bowling performance, and interactive filtering to provide a consolidated view of IPL performance.

## 🎯 Project Objective

The objective of this project is to build an interactive Business Intelligence dashboard that transforms IPL performance data into meaningful visual insights.

The dashboard focuses on:

- Team performance and win percentage
- Batting performance and run scoring
- Player strike rates
- Bowling performance and wicket taking
- Bowling economy
- Relationship between wickets and economy

## 🔬 Bowling Performance Quadrants

The **Economy vs Wickets** analysis classifies bowlers based on their wicket count and economy relative to the calculated average reference lines.

| Performance Quadrant | Description |
|---|---|
| High Wickets + High Economy | Higher wicket output with higher economy |
| High Wickets + Low Economy | Higher wicket output with lower economy |
| Low Wickets + High Economy | Lower wicket output with higher economy |
| Low Wickets + Low Economy | Lower wicket output with lower economy |

This provides a simple framework for comparing different bowling performance profiles.
